# 中文化分析

对象：基于 v2.8.2 的 Angular 界面和 Electron 桌面应用，面向需求分析、开发和测试人员。
范围：静态界面、动态提示、导航、表单、错误、导出字段、日期、桌面菜单和 AI 生成内容。
风格：精准、简洁、自然的简体中文，采用 EXTEND.md 中的统一术语。

难点：显示文本与持久化值、IPC 名称、路由、JSON 键、模型 ID 和提示模板混在一起。
只翻译显示与自然语言内容；修改显示时保留代码结构、插值和协议格式。
AI 自然语言输出默认中文，保留 JSON 字段名、程序代码、专有名词与用户明确指定的语言。
按静态模板、动态界面文案、Electron 消息和提示词划分初稿，再由主代理校审。
